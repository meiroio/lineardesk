# Repository instructions

- This project uses Bun. Use `bun run`, `bunx`, and `bun install --frozen-lockfile`.
- Before running any package-manager command, confirm the tracked lockfile and the `packageManager` field in `package.json`.
- Do not run npm, pnpm, or Yarn commands or create their lock/workspace files.

## ui-sdk

- Before using ui-sdk, follow the `ui-sdk` skill if it's installed, and read `node_modules/@ui-sdk/react/docs/llms.txt`.
- To build a new component, also search `node_modules/@ui-sdk/react/docs/core.md` by heading, and read `rendering.md` next to it.
